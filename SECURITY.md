# Security Policy

## Supported Versions

Only the latest release version of the Business Incubator Platform is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do NOT open a public issue. Instead, follow these steps:

1. Send an email to the project maintainers at **security-incubator@example.com** (replace with your security contact email) explaining the vulnerability in detail.
2. Include a description of the issue, the potential impact, and step-by-step instructions or proof-of-concept code to reproduce the issue.
3. We will acknowledge receipt of your report within 48 hours and work with you to resolve the problem.

## Our Commitment

* **Responsible Disclosure**: We will work to patch the vulnerability within a reasonable time frame (usually 30 days or less).
* **Credit**: We will credit you in the release notes and security notices when the issue is resolved, unless you prefer to remain anonymous.
* **Public Notice**: A public security advisory will be issued once a patch has been released.
