# Getting Support

Thank you for using the Business Incubator Platform & DBMS! If you run into issues or have questions, here are the best channels to get help:

## 🔍 1. Search Existing Issues & Q&A
Before opening a request, please check our:
- [Issue Tracker](https://github.com/aelaraby6/Business-Incubator-Platform-DBMS/issues) - To see if someone else has already reported the bug or asked your question.
- [Wiki / Documentation](docs/) - For documentation details and architectural overviews.

## 💬 2. Community Discussions
If you have a general question, need deployment advice, or want to discuss project ideas, please use our **GitHub Discussions** page (if enabled on the repository) or join our community channel.

## 🐛 3. Filing Bug Reports & Feature Requests
- For bugs: File a detailed report using the **Bug Report** template under [Issues](https://github.com/aelaraby6/Business-Incubator-Platform-DBMS/issues/new).
- For feature requests: Propose your idea using the **Feature Request** template.

---

## Response Times
This is an open-source project maintained by volunteers. While we try our best to respond to community inquiries within 3-5 days, we cannot guarantee immediate support. If you are an incubator administrator and require professional support contracts, please contact the lead authors.
